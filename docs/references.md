# References

The following sources provide background for SSI, EnDat, and the STM32 development platform. Check the current vendor documentation and applicable revision before using any specification for a production design.

1. SICK AG, “SSI Interface Description – Synchronous Serial Interface for Absolute Encoders,” Technical Information, document 8026422, revision 2022-02-08, 2022.
2. DR. JOHANNES HEIDENHAIN GmbH, “EnDat 2.2 Implementation Guide,” document 1302636-01-A-02, September 2021.
3. DR. JOHANNES HEIDENHAIN GmbH, “EnDat 2.2 Interface Specification,” document 296403-xx. Potential reference for bit-level timing and frame content; obtain the official document directly from the publisher.
4. STMicroelectronics, “UM1462: Discovery Kit with STM32F406VG MCU – User Manual.” Verify the current revision and applicability to the actual board with STMicroelectronics.
5. STMicroelectronics, “STM32F405/415, STM32F406/416, STM32F426/436, STM32F429/439 Datasheet,” document DM00036051.
6. STMicroelectronics, “RM0090: STM32F405/415, STM32F406/416, STM32F426/436, STM32F429/439 Advanced Arm-based 32-bit MCUs – Reference Manual.”
7. Arm Limited, “Cortex-M4 Technical Reference Manual.”
8. HEIDENHAIN, “EnDat 2.2 Application Notes,” document 622024-xx.
